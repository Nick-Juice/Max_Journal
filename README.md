# MAX Journal

Minimal, responsive login page built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — login page structure
- `style.css` — royal-blue styling and light/dark themes
- `script.js` — theme toggle and password visibility
- `public/max-logo.svg` — editable MAX Journal logo

## Change the logo
Edit `public/max-logo.svg` on GitHub whenever you want to update the logo. The login page loads this file directly.

## Current status
This is a front-end login page. Real sign-in, password recovery, and account creation still need to be connected to an authentication service.
